DATA PROCESSING AGREEMENT (DPA)

LAST UPDATED: NOVEMBER 22, 2026 • VERSION 3.0

This Data Processing Agreement ("DPA") applies between the website operator or brand embedding the BrainSweep widget ("Publisher" or "Controller") and BrainSweep, operating in Nigeria ("Widget Provider" or "Processor").

CORE COMMITMENT TO PUBLISHERS: In B2B Embed Mode (?embed=true), the widget does not prompt your visitors for personal registration or show a cookie banner over your page. Analytics inside embeds defaults to OFF unless you explicitly pass consent=1 after obtaining visitor consent on your site. We never sell or misuse your audience's data.

1. SCOPE & ROLES

  • 1.1 Controller & Processor: The Publisher acts as the Data Controller for visitors on its web properties, and the Widget Provider acts as the Data Processor (and Service Provider under the NDPA 2023, GDPR Art. 28, and CCPA) for the embedded game iframe.
  • 1.2 What the Embed Processes: By default, an embedded widget (?embed=true) stores only local game state in the visitor's browser localStorage and emits client-side window.parent.postMessage gameplay events to the Publisher's host page. If the Publisher passes consent=1 and analytics is enabled, anonymous gameplay counts tagged with the Publisher's referrer domain (embed_domain) are recorded without any email or username.

2. PROCESSOR OBLIGATIONS

  • 2.1 No Sale or Cross-Site Profiling: The Widget Provider shall never sell, rent, or use Publisher visitor data for third-party advertising or cross-site behavioral profiling.
  • 2.2 Origin Isolation: The widget runs inside an isolated iframe origin and cannot read cookies, DOM fields, or session tokens from the Publisher's parent page.
  • 2.3 Sub-Processors: The Publisher authorizes the use of Vercel Inc. (static web hosting over HTTPS), Google LLC (Google Apps Script / Google Sheets for leaderboard storage when used), and Umami Cloud (Umami Software, Inc.) for consent-gated anonymous gameplay analytics when enabled and consented.

3. INCIDENT NOTIFICATION & DELETION

  • 3.1 Notification: If the Widget Provider becomes aware of a security breach affecting personal data processed under this DPA, it will notify the Publisher promptly via email.
  • 3.2 Deletion Requests: Upon written request from the Publisher to madebykubo@gmail.com, the Widget Provider will delete any stored telemetry or leaderboard records associated with the Publisher's domain within 30 days.
