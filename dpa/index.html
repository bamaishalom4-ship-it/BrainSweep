DATA PROCESSING AGREEMENT (DPA)

STANDARD B2B WIDGET DATA PROCESSING ADDENDUM • REVISION 2026.11

This Data Processing Agreement ("DPA") forms part of the B2B Widget Licensing Agreement between the media entity or website operator embedding the BrainSweep widget ("Publisher" or "Data Controller") and MadeByKubo / BrainSweep ("Widget Provider" or "Data Processor").

CORE COMMITMENT TO PUBLISHERS: The Widget Provider acts strictly as a Data Processor (and "Service Provider" under the CCPA/CPRA) on behalf of the Publisher. We will never sell, rent, retarget, profile, or commercially exploit your audience's personal data.

1. ROLES & SCOPE OF PROCESSING

  • 1.1 Controller & Processor: With respect to end-users visiting the Publisher's digital properties ("Audience Members"), the Publisher acts as the Data Controller determining the context of the embed, and the Widget Provider acts as the Data Processor operating the sandboxed iframe game session.
  • 1.2 Nature & Purpose: Processing is strictly limited to rendering the BrainSweep cognitive game widget (?embed=true), storing local user preferences (theme, sound, consent state), and computing anonymized session scores and aggregate engagement metrics for the Publisher.
  • 1.3 Categories of Data Subjects: Visitors and readers of the Publisher's website who interact with the embedded BrainSweep iframe.

2. PROCESSOR OBLIGATIONS & NO-MISUSE COVENANT

The Widget Provider hereby warrants and covenants that it shall:

  • 2.1 Process Only on Documented Instructions: Process Audience Member data solely to deliver and maintain the embedded widget functionality requested by the Publisher.
  • 2.2 Strict Prohibition on Data Sale or Cross-Site Profiling: Never sell, lease, or share Audience Member data with advertising networks, data brokers, or third parties, nor combine Audience Member data across unaffiliated publishers for behavioral profiling.
  • 2.3 Data Minimization in Embed Mode: When loaded with ?embed=true, the widget operates without mandatory personal registration, keeping gameplay telemetry anonymous by default.
  • 2.4 Confidentiality: Ensure that all personnel authorized to maintain the widget infrastructure are bound by strict confidentiality obligations.

3. TECHNICAL & ORGANIZATIONAL SECURITY MEASURES

Pursuant to GDPR Article 32, the Widget Provider maintains industry-standard security controls, including:

  • Sandboxed Iframe Isolation: The widget runs inside an isolated origin boundary and does not read or access first-party cookies, DOM inputs, or session tokens belonging to the Publisher's parent page.
  • Encryption in Transit: All widget assets and API telemetry endpoints are served exclusively over HTTPS / TLS 1.3.
  • Zero Third-Party Ad Trackers: The embedded widget contains zero third-party ad-tech pixels or invasive fingerprinting scripts.

4. SUB-PROCESSORS & INTERNATIONAL TRANSFERS

The Publisher authorizes the Widget Provider to utilize vetted cloud infrastructure sub-processors (such as Vercel Inc. for edge CDN hosting and Google Cloud / Workspace infrastructure for encrypted score storage) bound by Standard Contractual Clauses (SCCs) and equivalent data protection safeguards.

5. AUDIT RIGHTS, INCIDENT NOTIFICATION & DELETION

  • 5.1 Security Incident Notification: In the event of a confirmed personal data breach affecting Publisher Audience Members, the Widget Provider shall notify the Publisher without undue delay (and within 48 hours of discovery).
  • 5.2 Deletion Upon Termination: Upon termination of the Publisher's embed deployment, the Widget Provider shall delete or irreversibly anonymize any Publisher-specific telemetry logs within thirty (30) days.
