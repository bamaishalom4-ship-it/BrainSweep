HOW TO PASTE THE CODE INTO YOUR WEBSITE

            
    
              
  1. Configure & Copy: Set your domain, difficulty, theme, and optional sponsor CTA above, then click COPY CODE.
    2. 
              
  2. Open Your CMS / HTML Editor: Add a Custom HTML / Embed Block in WordPress, Webflow, Ghost, Substack, or your custom frontend.
    3. 
              
  3. Paste Into the HTML Body: Paste the <iframe>...</iframe> snippet where you want the game to appear. Recommended height is 640px so the header, target dock, arena, and drop zone fit at both 400px and 640px widths without clipping.
    4. 
              
  4. Tap-to-Start & Auto-Pause: The embedded game displays a "TAP TO PLAY" start card on load and automatically pauses the timer if the reader scrolls the iframe out of view.

HOST PAGE POSTMESSAGE EVENTS API

            
In embed mode (?embed=true), BrainSweep emits real-time events to your parent page via window.parent.postMessage:

            
window.addEventListener('message', (event) => {
  if (event.data && event.data.source === 'brainsweep') {
    // event.data.type: 'ready' | 'start' | 'end' | 'cta_click'
    console.log(event.data.type, event.data.payload);
  }
});

          

        

      


      
4. URL QUERY PARAMETER REFERENCE

      
Swipe or scroll horizontally on mobile to inspect all columns.

      

        

          
            

              PARAMETER
              VALUES
              DESCRIPTION
            

          
          
            

              embed=true
              true | 1
              Required for B2B embeds. Hides external navigation, bottom bars, registration prompts, and cookie banners. Shows a "TAP TO PLAY" start card and end-of-round sponsor card.
            

            

              difficulty
              easy | medium | hard
              Sets the starting difficulty level (defaults to easy).
            

            

              theme
              amber | green | cyan | magenta | clear
              Sets the visual color palette (including clear for high-contrast plain sans-serif numbers).
            

            

              pattern
              spiral | zigzag | random | wave | mixed
              Configures the movement trajectory pattern of the numbers inside the arena.
            

            

              daily=1
              1 | true
              Launches directly in seeded Daily Sweep mode (identical number layout for all players that day in Africa/Lagos time).
            

            

              brand_logo
              https://...
              Optional HTTPS image URL displayed in the sponsor bar inside the embed.
            

            

              brand_color
              #RRGGBB
              Optional 6-digit hex accent color applied to sponsor highlights.
            

            

              sponsor_text
              Up to 40 chars
              Sponsor attribution text (e.g., Powered by XYZ Bank). Plain text only.
            

            

              cta_text & cta_url
              24 chars & https://...
              Renders a sponsor call-to-action button on the end-of-round card opening in a new tab with rel="noopener sponsored".
            

            

              consent=1
              1 | true
              Signals that the host Publisher has obtained analytics consent from the visitor. Without this, analytics remains off in embed mode.
