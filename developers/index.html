HOW TO PASTE THE CODE INTO YOUR WEBSITE

          
    
            
  1. Configure & Copy: Enter your website's domain name above, pick your starting difficulty and color theme, and click the orange COPY CODE button.
    2. 
            
  2. Open Your Website Editor: Go to the page or article where you want the game to appear and open an HTML Block (in WordPress, Webflow, Ghost, Squarespace, or Wix, choose "Custom HTML" or "Embed Code").
    3. 
            
  3. Paste Into the HTML Body: Paste the copied <iframe>...</iframe> code directly inside your page's HTML <body> section where you want readers to play.
    4. 
            
  4. Publish: Save and publish your page. The widget includes loading="lazy", meaning it will never slow down your article's initial page load!
    5. 
          

        


        

          
HOW TO TEST IN A SANDBOX BEFORE GOING LIVE

          
    
            
  • Instant Browser Test: You can test your snippet right now using free HTML sandboxes like CodePen.io, JSFiddle.net, or a local test.html file on your computer — simply paste the snippet into the HTML panel.
    • 
            
  • Mobile Width Check: Resize your preview container down to 360px–400px wide to verify that the widget scales cleanly with zero horizontal scrollbars.
    • 
            
  • Off-Screen CPU Pause: Scroll the page so the iframe is out of view — BrainSweep's built-in IntersectionObserver automatically pauses the 60fps canvas loop while offscreen to save your readers' battery.

4. URL QUERY PARAMETER REFERENCE

      

        
          

            PARAMETER
            VALUES
            DESCRIPTION
          

        
        
          

            embed=true
            true | 1
            Required for B2B embeds. Hides the 5-icon bottom navigation bar, home back buttons, registration popups, and external footer, showing only the core arena, timer, and score.
          

          

            difficulty
            easy | medium | hard
            Sets the starting difficulty level when the embedded game launches (defaults to easy).
          

          

            theme
            amber | green | cyan | magenta
            Sets the CRT color palette of the widget and SVG logo to match your publication's branding.
          

          

            pattern
            spiral | zigzag | random | wave | mixed
            Configures the movement trajectory pattern of the numbers inside the arena.
          

          

            domain
            your-site.com
            Identifies your publisher domain for B2B license verification and aggregated telemetry.
